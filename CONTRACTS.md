# Build contracts (v1)

Personal blog + phone-first PWA editor. Next.js 16 App Router on Vercel. **Read `AGENTS.md` first** — this Next version differs from training data; check `node_modules/next/dist/docs/` before using any Next API (async `params`/`cookies()`, route handlers, `proxy.ts`, etc.). `cacheComponents` is OFF.

Shared, already written, **do not modify**: `lib/types.ts`, `lib/store/index.ts`, `lib/studio/parse.ts`, `lib/models.ts`, `app/layout.tsx`, `app/globals.css` (design tokens — use these CSS variables, never hard-code colours/fonts), `next.config.ts`, `package.json` deps (ask in your report if you need a new dep; don't install).

Styling: CSS Modules next to components (`*.module.css`). No Tailwind, no UI libs. Mobile-first; touch targets ≥ `var(--tap)`; respect `--safe-top/--safe-bottom`. Look: printed pamphlet — hairline rules (`1px solid var(--rule)`), no drop shadows, no rounded cards, no gradients, no emoji icons (use text labels or tiny inline SVG). UI chrome in `var(--font-ui)` (small caps/uppercase labels at 0.72rem, letter-spacing .08em are the house style); reading text in `var(--font-body)`; titles in `var(--font-display)`.

Only touch files in your own stream's ownership list. Run `npx tsc --noEmit` and `npx eslint <your files>` before reporting. Don't run `next build` or `next dev` (other streams are writing in the same tree) — the lead integrates. Don't `git commit`.

## Env
`ADMIN_PASSWORD`, `SESSION_SECRET`, `DATABASE_URL` (Neon Postgres; absent → file store at `.data/db.json`, local dev only), `OPENROUTER_API_KEY`, `GITHUB_TOKEN` (optional), `AI_MOCK=1` (deterministic fake AI replies, for tests), `MODEL_CODE|WRITING|FAST|…` overrides.

## Routes and ownership

### Stream A — data + auth (`lib/store/file.ts`, `lib/store/postgres.ts`, `lib/auth.ts`, `lib/slug.ts`, `app/api/auth/**`, `app/api/posts/**`, `app/api/settings/**`, `app/login/**`)
- `lib/auth.ts` exports: `isAuthed(): Promise<boolean>` (reads the session cookie), `requireAuth(): Promise<Response | null>` (returns a 401 JSON Response if not authed, else null — every `/api` handler except login calls it first), `createSession()/clearSession()`. Cookie `session`: HMAC-SHA256 signed expiry using `SESSION_SECRET`, httpOnly, sameSite lax, secure in prod, 60 days. Constant-time password compare against `ADMIN_PASSWORD`. If `ADMIN_PASSWORD` is unset, login always fails with a clear message.
- `POST /api/auth/login {password}` → `{ok:true}` | 401 `{error}`; `POST /api/auth/logout` → `{ok:true}`.
- `GET /api/posts` → `{posts: PostSummary[]}`; `POST /api/posts` → `{post: Post}` (empty draft: title "", content `{type:"doc",content:[{type:"paragraph"}]}`).
- `GET /api/posts/[id]` → `{post}` | 404; `PATCH /api/posts/[id]` body = any of `{title, slug, excerpt, content, status, publishAt}` → `{post}`; `DELETE` → `{ok:true}`.
  - PATCH rules: `status:"published"` → `publishAt = now` unless the post is already published; `status:"scheduled"` requires future `publishAt` (400 otherwise); `status:"draft"` → `publishAt = null`. When moving to published/scheduled with empty slug, derive from title via `slugify`; always make slug unique (`-2`, `-3`…). 400 if title is empty on publish. After any PATCH/DELETE that changes what is public, call `revalidatePath("/")`, `revalidatePath("/posts/[slug]", "page")` and `revalidatePath("/feed.xml")` (check the docs for the exact API).
- `GET /api/settings` → `{settings}`; `PATCH /api/settings` partial → `{settings}`.
- Postgres store uses `@neondatabase/serverless`, creates tables lazily (`create table if not exists`, once per process). File store: JSON at `.data/db.json`, atomic write.
- `/login`: minimal password form (client component), on success `location.href = next || "/write"`.

### Stream B — AI + GitHub backend (`lib/openrouter.ts`, `lib/prompts.ts`, `lib/github.ts`, `lib/lang.ts`, `app/api/ai/**`, `app/api/github/**`)
All handlers call `requireAuth()` from `@/lib/auth` first (Stream A writes it concurrently; signature above). Models via `modelFor(job)` from `lib/models.ts`. OpenRouter: `POST https://openrouter.ai/api/v1/chat/completions`, `Authorization: Bearer`, headers `HTTP-Referer`, `X-OpenRouter-Title`; `stream:true` gives SSE with `choices[0].delta.content`, ignore comment lines, ends `data: [DONE]`. Missing key → 500 `{error:"OPENROUTER_API_KEY is not set"}`. Upstream errors → pass a readable `{error}` with the status.
- `POST /api/ai/studio` body `{kind:"code", messages: ChatMessage[], current?: CodeData, context?: {files: {repo:string, path:string, ref:string, content:string, startLine?:number, endLine?:number}[]}, post?: {title:string, text:string}}` → **streamed `text/plain`** of the raw assistant text (no SSE framing). The system prompt makes the model answer with one or two plain sentences plus exactly ONE fenced block containing the complete current snippet, opener like ```` ```ts title="server.ts" ````; `lib/studio/parse.ts#extractArtifact` must parse the result. `current` is the snippet being edited (later turns / reopened blocks); context files are reference material (cap total context ~60k chars, truncate with a marker); `post` gives the surrounding article so the snippet fits it. Snippets for blog posts: short, focused, real, no placeholder comments, no explanation inside the code unless asked.
- `POST /api/ai/buddy` body `{mode: BuddyMode, title: string, paragraphs: {i:number, text:string}[]}` → `BuddyResult`. Job `writing`. The server loads `settings.voiceNotes` and up to 3 most recent public posts (plain text, ~1500 chars each) as voice samples. The prompt is the point of this feature: act as a line editor who preserves the author's voice — smallest possible edits, keep their words, rhythm, idioms and quirks, never add flourish, no em-dash insertion, no "AI" phrasing, fix real errors, flag don't rewrite; `polish` → grammar/clarity/concision suggestions with exact `quote` substrings (verify server-side that each `quote` occurs in paragraph `i`; drop any that don't; drop no-op edits); `structure` → mostly `notes` (ordering, missing steps, weak opening/ending, where a code snippet or example would help), plus at most a few suggestions. Ask for JSON; parse defensively (strip fences, find the outermost object). Assign `id`s server-side.
- `POST /api/ai/meta` body `{title:string, text:string}` → `{titles: string[] (3), excerpt: string, slug: string}`. Job `fast`.
- `AI_MOCK=1`: studio streams a canned note + fenced block in several small chunks with ~40ms gaps (echo the last user message in the note); buddy returns 2 suggestions built from real substrings of the supplied paragraphs + 1 note; meta returns canned values. No network.
- GitHub (REST v3, `GITHUB_TOKEN` optional, `X-GitHub-Api-Version` header, friendly errors for 403 rate limit / 404):
  - `GET /api/github/repos?q=` → `{repos: RepoInfo[], authed: boolean}`. Empty `q` → the token user's repos by recent push (or `[]` without token); `q` containing `/` → that exact repo if it exists (else fall through to search); otherwise repo search (top 15).
  - `GET /api/github/tree?repo=o/n&ref=&path=` → `{entries: TreeEntry[], ref: string}` (dirs first, then files, alphabetical). `ref` defaults to the default branch.
  - `GET /api/github/file?repo=o/n&path=&ref=` → `FileResult` (ref resolved to a commit sha so `htmlUrl` is a permalink; refuse binary or > 300 KB with 413 `{error}`).
  - `lib/lang.ts`: `langFromPath(path): string` → shiki language id (`"text"` fallback). Also used by other streams.

### Stream C — public site + PWA shell (`app/(site)/**`, `app/feed.xml/route.ts`, `components/render/**`, `lib/highlight.ts`, `lib/text.ts`, `app/manifest.ts`, `public/**`, `scripts/make-icons.py`, `app/not-found.tsx`)
- `/` (list of public posts) and `/posts/[slug]`; both `export const revalidate = 60` and read through `getStore().listPublic()/getPublicBySlug()` + `getSettings()` — scheduled posts appear on their own once `publishAt` passes. `generateMetadata` for titles/OG. `/feed.xml` RSS 2.0.
- `components/render/Doc.tsx`: async server component `<Doc doc={DocNode} />` rendering Tiptap JSON → React, no Tiptap dependency. Node types: `doc, paragraph, heading(level 2|3), bulletList, orderedList, listItem, blockquote, horizontalRule, hardBreak, codeBlock(attrs.language), text`, marks `bold, italic, strike, code, link(href)`, and `genBlock` (attrs = `GenBlockAttrs`): `kind:"code"` → `<CodeFigure data={CodeData}/>` (shiki highlighted server-side via `lib/highlight.ts`, filename bar, caption, "from owner/repo · path#Lx-Ly" source link when `data.source`), `kind:"repo"` → `<RepoCard data={RepoData}/>`. Unknown nodes/kinds render nothing. `lib/highlight.ts`: `highlight(code, lang): Promise<string>` (html; cached highlighter; unknown lang → plain escaped). `lib/text.ts`: `docToText(doc): string`, `docToParagraphs(doc): string[]` (plain text of each top-level text block, used by other streams — write this first), `readingMinutes(doc)`.
- `components/render/**` must also be importable for the editor's preview: export `CodeFigure` and `RepoCard` as server components taking only serialisable props.
- PWA: `app/manifest.ts` (name from a constant "Write", `start_url: "/write"`, `display: "standalone"`, theme/background from tokens' light values), icons 192/512/maskable + `apple-touch-icon.png` (180) generated by `scripts/make-icons.py` with Pillow (a vermilion pilcrow ¶ or pen-nib mark on paper; commit the PNGs), favicon. No service worker in v1.
- The site design is yours: editorial pamphlet per the tokens. Masthead with site title/tagline, dated index, generous post typography at `--measure`, a small footer with RSS. No link to `/write` in the public UI.
